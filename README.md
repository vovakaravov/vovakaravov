## Engine & 3D Pipeline Tools

- **[Juicer Runtime & Exporter](https://github.com/vovakaravov/juicer-runtime)** — Custom data-driven rendering runtime in **Odin + SDL3 GPU (SPIR-V shaders)** paired with a **Blender 5.0+** `F5` one-click binary scene exporter.
- **[Anti-Rigger](https://github.com/vovakaravov/anti-rigger)** — Modular Blender rigging addon built for Unity, Godot, and Unreal (`TGT-` control hierarchy, unscaled deform bones, Hand/Foot IK, gimbal-safe Foot Roll, IK/FK driver switches).
- **[VK Baking Tools](https://github.com/vovakaravov/vk-baking-tools)** — Automated Cycles baking utilities for Blender 5.0 (Multires normals, multi-material group/atlas baking, AO with glTF node auto-hookup).
- **[Mixamo Animation Consolidator](https://github.com/vovakaravov/animation-consolidator)** — Batch-imports Mixamo `.fbx` folders onto a single armature and cleans up temporary skeletons and orphan meshes.
